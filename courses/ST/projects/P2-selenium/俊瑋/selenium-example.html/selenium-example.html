Example: GUI testing with Selenium

SUT
  • a web page for user registration
SUT Requirement
  1. Existed username can not be used to register.
  2. All fields in the application form should be filled in.
Test Requirement
  1. The "check the username" button should act normally (when clicked, tells the user the name is legal or not.)
  2. When the submit button is clicked, all fields have to be filled in (including the Term-of-Service checkbok), or a pop-up alert will be displayed.
